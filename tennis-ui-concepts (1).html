발송 내역의 기준

건수는 텔레그램 메시지 발송 성공 수입니다. 빈자리 발견 건수나 사용자의 읽음 여부와 구분합니다. 한 메시지에 여러 빈자리가 담겨도 메시지 1건으로 집계하며, 발송 실패는 성공 건수에서 제외합니다. 발송된 메시지는 당시의 기록이므로 현재 빈자리로 표시하지 않습니다.

실제 적용 시 필요한 작업

이번 변경은 화면 시안입니다. 현재 코드에는 관리자 통계용 telegram_sent / telegram_failed 이벤트가 있지만 사용자별 메시지 이력 화면은 별도 구현이 필요합니다. 실제 적용 시 본인에게 발송된 메시지만 조회하도록 하고, 한국 시간 기준 발송 시각·시설·예약 대상 날짜/시간·메시지 식별자·성공/실패를 연결해야 합니다. 기존 기록에 상세 내용이 없다면 과거 내용을 추정하지 않고 ‘상세 기록 없음’으로 표시해야 합니다.

실패 후 재시도에 성공한 같은 발송 건은 상태를 갱신해 중복 집계하지 않도록 설계합니다. 실제 보관 기간과 집계 가능 범위가 정해지면 ‘누적’ 기준도 함께 명시해야 합니다.

확인 범위

기존 녹색·라임·아이보리 색상과 등록 흐름을 유지했습니다. 목업은 예시 데이터로 작동하며 실제 텔레그램·예약 API를 호출하지 않습니다. 주요 화면과 필터·집계·하단 메뉴 동작은 로컬 검사로 확인했습니다. 브라우저 렌더링 검증은 현재 환경 제한으로 수행하지 못했습니다.
