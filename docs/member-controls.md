# 시간 무관 알림 · 이용 차단 · 개인 조회 로그

- 새 알림의 "시간대 상관없음"을 선택하면 해당 시설의 전체 운영 시간을 서버에서 계산한다. 날짜·시설·코트·이용시간 조건은 유지한다. 면목은 이용 날짜의 계절별 운영 회차를 사용한다.
- /admin 에서 관리자 토큰으로 인증한 뒤 사용자별 "사용자 차단" / "재활성화" 버튼을 사용한다. 차단은 기존 모든 기기의 API 접근과 신규 연결을 막고, 보관된 알림을 모두 끈다. 미사용 연결 코드는 폐기한다. 조회 도중 차단돼도 발송 직전 최신 이용 상태를 다시 확인한다.
- 재활성화하면 유효한 기존 로그인으로 이용할 수 있고 알림은 자동으로 켜지지 않는다. 기존 초대코드는 재사용할 수 없다.
- /admin 의 초대코드 관리에서 미사용 초대코드를 비활성화/활성화할 수 있다. 사용한 코드는 사용자 차단으로 관리한다.
- 개인 상태 API는 공용 로그 원문을 전달하지 않는다. 조회 당시 대상 사용자·알림 ID를 기록하고, 본인의 시설·날짜 오류·발송 오류만으로 표시 내용을 재구성한다. 관련 없는 제공자 상태와 공용 결과 캐시는 응답에서 제외한다. 대상 정보 없는 과거 구조화 로그는 본인이 등록한 시설 기준으로 필터링하고, 구조 없는 과거 원문은 표시하지 않는다.
- 한 달 무료 이용 후 차단 여부는 운영자가 결정한다. 이번 변경에는 자동 결제 또는 자동 이용기간 만료 정책이 포함되지 않는다.

검증: 두 사용자 API 테스트로 첫/마지막 시간 매칭, 올림픽 전체 시간, 면목 계절 변경, 로그·날짜·발송 오류 격리, 관리자 권한, 초대코드 사용 제한, 기존 로그인 차단과 재활성화를 확인한다.
