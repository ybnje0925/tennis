# 올림픽 실제 빈자리 누락 수정 (2026-10-11)

운영에서 10월 12일 달력의 가능 3건과 08~09시, 09~10시, 16~17시 신청가능을 확인했다. 기존 조회는 시간표를 빈 배열로 반환했다.

원인과 수정:
- 달력을 감싼 상위 li까지 날짜 셀로 읽어 전체 예약 영역을 12일로 오인했다. 하위 날짜 셀을 포함하는 상위 요소를 제외한다.
- 날짜 셀의 첫 a는 날짜 번호이며 시간표 조회 버튼이 아니었다. 해당 셀의 가능 건수 링크를 선택한다.
- 클릭 후 다른 날짜의 시간 문자열로 준비 완료를 판정하지 않고 목표 월·일 시간표를 기다린다.
- 현재 사이트는 통합 코트 지도다. 분리된 실내/실외 선택기가 없으면 날짜당 한 번 조회해 중복을 피한다.
- 활성 DATE 탭의 실제 place-hotspot 버튼만 읽고, aria-disabled·is-disabled와 숨겨진 COURT 탭을 제외한다. enabled 버튼의 N번 구역 라벨을 실제 코트 번호로 읽는다. 안내문·시간·결제 유의사항 숫자는 코트로 해석하지 않는다.
- 다음 시간 선택 전 기존 체크를 해제한다.
- 시간 무관 알림은 실제 조회된 모든 시간을 매칭한다.
- 달력에는 가능 건수가 있는데 시간표를 읽지 못하거나 시간 선택에 실패하면 확인 불가 오류를 반환한다.

검증: 실제 Chromium에서 상위 탭 및 날짜 번호 링크를 포함한 DOM으로 올바른 링크 선택, 시간 선택 교체, 숨김/비활성 지도 제외를 확인했다. 순수 파서 회귀 테스트도 추가했다.
