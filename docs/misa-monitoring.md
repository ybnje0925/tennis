# 미사한강공원 조회 시간 제한

첨부 예약 규칙에 따라 한국 시간 평일 09:00 이상 18:00 미만에만 조회한다. 주말과 공휴일·대체공휴일은 쉬며, 신청일 기준 3~15일 뒤 이용 날짜만 조회한다. 이용일이 주말·공휴일인 것은 제한하지 않는다.

스케줄러에서 미사 알림 조건만 제외하므로 하남종합운동장 등 다른 시설은 계속 조회한다. 미사만 있으면 provider 및 HTTP 호출 자체를 생략한다. 수동/진단 조회도 provider에서 같은 규칙을 적용한다. 등록된 조건은 삭제하거나 비활성화하지 않고 예약 기간이 되면 자동 재개한다.

공휴일은 @hyunbinseo/holidays-kr 5.2027.2의 번들 데이터로 판정하며 추가 네트워크 요청을 하지 않는다. 현재 2027년까지 지원한다. 미지원 연도는 안전하게 쉬므로 새 연도 달력이 나오면 패키지를 갱신한다. 임시공휴일 지정 시에도 갱신이 필요하다. 자료: https://github.com/hyunbinseo/holidays-kr (우주항공청 월력요항 기반).

기존 5분 주기는 유지한다. 예약 불가 시간의 조회 부하를 줄이는 변경이며 서버 기본 요금 자체를 없애는 것은 아니다.
